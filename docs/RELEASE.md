# Сборка Android APK

**Русский** · [English](RELEASE.en.md)

Fortem **1.0.3** · Android `versionCode 78`.

## Проект и зависимости

Корень Android-проекта содержит `settings.gradle.kts` и Gradle Wrapper.
Версия приложения и `versionCode` указаны в `app/build.gradle.kts`.
Версии Android SDK, NDK и CMake также закреплены в настройках проекта;
версии библиотек находятся в `gradle/libs.versions.toml`.

Проект открывается в Android Studio через **Open**. После синхронизации Gradle
среда предлагает установить недостающие компоненты SDK и NDK.
Командная сборка использует JDK 17 и не требует Android Studio.

```bash
# Запуск модульных тестов из корня проекта.
./gradlew :app:testDebugUnitTest
# Создание отладочного APK и проверка комплекта нативных библиотек.
./gradlew :app:verifyDebugNativeLibraries
```

В Windows используются те же задачи с `gradlew.bat`.
Отладочный APK находится в `app/build/outputs/apk/debug/`.

## Подписанный APK

1. В Android Studio: **Build → Generate Signed Bundle / APK → APK**.
2. Модуль: **app**.
3. Для обновлений используется существующий ключ: **Choose existing**, путь к
   хранилищу, имя ключа (**Alias**) и пароли. Для первого выпуска ключ создаётся
   через **Create new** и хранится вне каталога исходников с резервной копией.
4. Выбираются вариант **release** и каталог результата; затем **Create / Finish**.
5. Ссылка **Locate** в уведомлении открывает папку с готовым APK.

Одинаковый пароль хранилища и ключа допустим. Поля **Confirm** повторяют
соответствующий пароль. Закрытый ключ и пароли не входят в исходники или релиз.
Android устанавливает обновление поверх существующего приложения только при
совместимой подписи; отладочные и релизные ключи обычно различаются.

## Публикация

Релизный тег имеет вид `v<versionName>`. Имя APK — `Fortem-<versionName>.apk`.
APK размещается в GitHub Releases, а не среди исходников. Описание выпуска
содержит изменения поведения, требования к системе и доступные пакеты.

Перед выпуском проверяются запуск, оба тембра, касания и инерция карты,
педаль и необязательное закрепление, запись и перезапись, воспроизведение,
экспорт WAV, удаление и восстановление записей, оба языка интерфейса.
Проверка обновления включает сохранность собственных записей и настроек.
