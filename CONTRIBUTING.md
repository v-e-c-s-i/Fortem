# Участие в разработке

**Русский** · [English](CONTRIBUTING.en.md)

Сообщайте об ошибках через GitHub Issues. Укажите версию Fortem, версию Android или iOS,
шаги воспроизведения и ожидаемый результат. Для ошибок касания особенно полезны
схема пальцев или короткая видеозапись экрана, для ошибок высоты — строй, тоника,
опорная частота и конкретные ноты.

Предложения интерфейса сопровождайте конкретным примером поведения.
Изменения музыкальной модели — определением строя, источником и проверкой частот.
Новые варианты Scala должны иметь документированный набор интервалов.

## Номера версий

Используется схема `MAJOR.MINOR.PATCH`: исправления повышают PATCH, совместимые
новые возможности — MINOR, несовместимые изменения — MAJOR. Базовая версия —
`1.0.0`. Android `versionCode` и номер сборки iOS увеличиваются независимо от
публичного номера версии и не сбрасываются при смене MAJOR.

Версии задаются в `app/build.gradle.kts` для Android и в настройках проекта Xcode
для iOS. Релизный тег имеет вид `v<версия>`. Исправления документации не требуют
новой версии приложения.

## Переводы

Английские тексты находятся в `app/src/main/res/values/strings.xml`, русские — в
`values-ru/strings.xml`. Сохраняйте одинаковые ключи и типы аргументов форматирования;
подписи должны соответствовать обеим версиям руководств. Проверьте выбор языка,
длинные подписи и увеличенный системный шрифт. Названия пользовательских строев не переводятся.

```bash
# Проверить полноту переводов, аргументы и ссылки на ресурсы без Android SDK.
python3 tests/check_localization.py
```

## Проверка изменений

```bash
# Проверить логику и наличие зависимостей звукового движка в собранном APK.
./gradlew :app:testDebugUnitTest :app:verifyDebugNativeLibraries
```

Проверяйте касания, удержание <img src="docs/assets/ui/lock.svg" width="22" height="22" alt="Закрепление">, педаль <img src="docs/assets/ui/pedal.svg" width="22" height="22" alt="Педаль">,
запись <img src="docs/assets/ui/record.svg" width="22" height="22" alt="Запись">, остановку <img src="docs/assets/ui/stop.svg" width="22" height="22" alt="Остановка">, перезапись <img src="docs/assets/ui/rerecord.svg" width="22" height="22" alt="Перезапись"> и проигрывание <img src="docs/assets/ui/play.svg" width="22" height="22" alt="Проигрывание"> на устройстве.
[Обозначения кнопок](docs/USER_GUIDE.md#interface-controls).
Обновление математической модели должно сохранять воспроизведение старых записей.
Изменения интерфейса проверяйте при обычном и увеличенном системном шрифте.

Код распространяется по GPL-3.0-only. Сторонние ресурсы сохраняют отдельные лицензии.

Нативные проверки на Linux:

```bash
# Проверить загрузку WAV и обработку звука без Android-устройства.
g++ -std=c++20 -O2 -Wall -Wextra -Itests/native_stubs tests/native_audio_test.cpp app/src/main/cpp/piano_sample_bank.cpp -o /tmp/fortem-native-test
/tmp/fortem-native-test app/src/main/assets
```
